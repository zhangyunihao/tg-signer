# 中奖信息获取逻辑

本文档整理 giveaway 任务的「中奖识别 + 回扫 + 转发提醒」完整链路。核心实现在
`tg_signer/giveaway_core.py`，WebUI 配置读写与启动链路在 `tg_signer/webui/giveaway.py`。

## 1. 识别：`GiveawayEngine._check_win_message`

- **范围**：只看 bot 私聊消息（开奖通知由抽奖 bot 发给中奖人账号的私信）。
- **开关**：任务配置 `win_detect`（WebUI 任务编辑里的「中奖识别」），默认开启。
- **判定正则** `WIN_MESSAGE_RE`（样本来自 @LotteryBestBot）：

  ```
  中奖提醒 | 恭喜.{0,8}中奖 | 防伪编号
  ```

  三个特征均只出现在中奖消息里，参与清单/抽奖说明类回复不会误命中。
- **去重两级**：
  1. 进程内 `_win_handled` 集合：同一轮重复轮询只处理一次；
  2. 状态文件 `win:{msg_id}` 记录（`GiveawayState`）：跨重启不重复转发/推送。

## 2. 获取路径（三条）

| 路径 | 时机 | 说明 |
| --- | --- | --- |
| 实时监听 | 任务运行期间收到 bot 私聊消息 | 第一时间发现中奖 |
| 启动回扫 | 任务启动、连接完成后 | 补捡停机期间错过的通知 |
| 补漏轮回扫 | 每个补漏轮（`rescue_interval`）末尾 + 首扫完成后 | 增量补捡兜底 |

首扫完成后会再补一轮回扫：首扫新参与的 bot 需要立即建回扫基线（清除
参与记录后，启动回扫时目标列表为空）。

## 3. 回扫机制：`_sweep_bot_wins` / `_fetch_newer_bot_messages`

- **目标 bot 列表**：来自该账号的参与记录（`GiveawayState.bots_for`，按最近
  交互倒序）。参与过的 bot 才可能发来中奖私信；清除参与记录后列表为空，
  重新参与后重建。
- **水位线**：每账号 × bot 持久化「上次扫到的消息 id」（`win_watermarks`），
  增量只处理比水位线新的消息并推进水位线；仅前进不后退。
- **扫描量下限**：全局设置「中奖回扫条数」（`win_sweep_limit`，默认 50）。
  水位线后新消息不足下限时，越过水位线继续向更旧消息补扫，直到补满下限
  或翻完全部历史（已处理的中奖消息靠状态去重，不会重复提醒）。
- **分页**：按页拉取（`WIN_SWEEP_PAGE = 100` 条/页），因此单轮实际扫描条数
  落在「下限 ～ 下限+100」之间；最多翻 `WIN_SWEEP_PAGE_MAX = 20` 页兜底
  （防水位线异常时无限翻页）。
- **首次建基线**：首次见到某 bot（无水位线）时，按回扫条数一次性拉取最近
  N 条作为初始基线。
- **容错**：bot 未开过会话/已失效等拉取失败静默跳过（调试日志），不影响
  其他 bot；每 bot 每轮回扫记一行结果日志便于确认执行。

## 4. 命中后的动作

1. **转发原消息**到转发目标列表 `win_forward_targets`（全局设置，多目标）：
   - `"me"` = 收藏夹（Saved Messages，即与自己的对话）；
   - 数字目标（如 `-100xxx` 频道/群 id）必须是 int——字符串形式的数字会被
     Telethon 当作手机号 resolve 而报 `PHONE_NOT_OCCUPIED`，引擎统一归一化；
   - 单个目标失败不阻断其余目标与提醒。
2. **推送 `win` 事件**：进入 WebUI 消息中心/提醒，并持久化到告警文件。

## 5. 数据清理

WebUI「清除参与记录」按钮（`GiveawayState.clear()`）只清除已参与记录：

- 已参与记录被清空，相同抽奖链接对所有账号重新视为未参与；
- 中奖消息去重记录（`win:<msg_id>`）与各账号 × bot 的回扫水位线**保留**，
  清除后回扫仍从原水位线继续，已提醒过的旧中奖消息不会被重复推送；
- 回扫目标 bot 列表由参与记录与保留的 `win:` 记录共同决定，账号重新参与后
  会补充新 bot。

## 6. 配置速查

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 中奖识别开关（`win_detect`） | 开 | 关闭后不识别也不回扫 |
| 转发目标（`win_forward_target`） | `me`（收藏夹） | 多目标列表，数字 id 自动转 int |
| 中奖回扫条数（`win_sweep_limit`） | 50 | 每轮单 bot 扫描量下限（首次建基线同样用该值） |
